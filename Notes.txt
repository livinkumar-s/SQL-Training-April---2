CRUD 
------
Create ---> INSERT INTO tbname (col detail(optional)) VALUES (),()... 
Read ----> SELECT (col details) FROM tbname;
Update ---> UPDATE tbname SET col = val;
DELETE ---> DELETE FROM tbname; (recoverable when autocommit is off)
Truncate -> TRUNCATE TABLE tbname; (never recoverable)

SQL_SAFE_UPDATES --> Cannot update or delete more than 1 record. Where clause is must. condition should use PK.

SET SQL_SAKE_UPTATES=1;
